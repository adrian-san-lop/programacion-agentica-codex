# Personas, agentes y responsabilidades

Trabajar con agentes no elimina la responsabilidad humana. Cada participante tiene un papel diferente:

```text
Persona
→ define el objetivo, revisa las decisiones y valida el resultado

Agente principal
→ coordina la tarea y mantiene el contexto general

Skill
→ aporta un procedimiento especializado

Subagente
→ resuelve una tarea aislada y devuelve un resultado

Tool
→ ejecuta una acción concreta
```

Un MCP no es un miembro del equipo. Es una integración técnica que puede proporcionar Tools a Codex. Del mismo modo, una carpeta de documentación no crea subagentes: solo contiene información que un agente puede consultar.

La persona sigue siendo responsable de revisar cambios, permisos, resultados y decisiones que afecten al proyecto.
