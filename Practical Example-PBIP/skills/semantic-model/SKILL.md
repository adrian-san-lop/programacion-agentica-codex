# Skill: Semantic Model

## When to use

Use for inspecting or modifying tables, columns, relationships, perspectives, roles, and semantic model metadata.

## Procedure

1. Locate the actual `*.SemanticModel/` folder.
2. Determine whether the project uses TMDL or TMSL.
3. Read only files related to the requested object.
4. Check dependencies and relationships.
5. Review compatibility with measures and the report.
6. Validate the project in Power BI Desktop.

## Precautions

- Do not edit cache or local configuration files.
- Avoid global changes without an impact inventory.
- Preserve the project's existing format.
