# Skill: Report Design

## When to use

Use for reviewing pages, visuals, filters, bookmarks, and navigation consistency.

## Procedure

1. Identify the affected page and visuals.
2. Review the measures and fields used.
3. Check consistency of titles, formatting, and filters.
4. Preserve the existing visual pattern.
5. Validate the result visually in Power BI Desktop.

## Precautions

- Do not modify the entire report to solve a local issue.
- Do not change measures to solve a purely visual issue without checking the model.
